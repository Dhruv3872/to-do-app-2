# to-do app:

- A most basic version of a react-router app to showcase using react-router as framework with the following features:
  - React Redux
  - Redux Saga
  - Authentication
  - Axios
  - Mock Adapter
  - Exception handling

## Changes introduced in this commit:

- Renamed the services following PascalCase to follow camelCase since that is  
  more appropriate for files that are not React comopnents in a React project.
